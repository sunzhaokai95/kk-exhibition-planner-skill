# 实战案例

以下案例展示 KK 策展助手完整走完 6 步流程的过程。所有甲方信息、企业名称、地域信息、产品参数均已**匿名化处理**，仅保留策划方法论的应用过程。

| 案例 | 项目类型 | 叙事线路 | 推导范式 | 看点 |
|------|---------|---------|---------|------|
| [某精准医疗企业展厅](01-enterprise-hall.md) | A 企业展厅 | 梯式 + 立体式 | ① 受众驱动型 | 甲方已有大纲时，如何换视角重组提升 |
| [某市城市生态科普馆](02-eco-museum.md) | B 科普馆 | 平行式 | ③ 破局立意型 | 政府项目"拒绝同质化"时，如何破局立意 |

两个案例分别走了不同的推导范式（①受众驱动 / ③破局立意），展示 Skill 应对不同项目场景的适应性。
