# 博物馆/文化馆策划指南

## 信息收集清单

### 基本信息
- 场馆名称 / 项目名称
- 场馆类型（历史博物馆 / 纪念馆 / 非遗馆 / 校史馆 / 档案馆 / 科技馆）
- 建筑面积与展陈面积（分层填写）
- 项目交付时间节点

### 内容主体
- 核心展示对象（地域历史 / 特定人物 / 某类文物 / 某项技艺 / 某段事件）
- 是否有馆藏文物/实物，大致数量与类型
- 是否有现成的学术研究成果、史料文献
- 内容的时间跨度（如：从史前到当代）
- 必须展示的重点内容（领导要求/政策要求/标志性内容）

### 受众与定位
- 主要参观人群（本地市民 / 学生研学 / 外地游客 / 专业研究者）
- 教育目标（知识普及 / 价值传承 / 爱国教育 / 专业研究）
- 是否需要兼顾运营（文创、研学、临展空间）

### 约束条件
- 政策导向、上级指导意见
- 内容审查要求（重大历史/人物需符合官方表述）
- 同地区同类场馆现状（差异化定位需要）

## 项目分析框架

### 1. 内容资料的三层结构
博物馆/文化馆策划的核心是「学术内容的故事化」。先按三层梳理资料：
- **理性资料**：基础知识体系、史实、数据、文献（保证准确）
- **感性资料**：故事、人物、传说、情感细节（产生共鸣）
- **综合资料**：政策、市场、当代解读（连接现实）

### 2. 找到内容的「魂」
不要平铺直叙地罗列历史。要找到：
- 这片土地/这个人物/这段历史最独特的精神内核是什么？
- 有没有一个「角度」能让枯燥的内容变得动人？（如《万历十五年》用一年解读明史）
- 能否从「一个人、一件事、一群人、一堆事」切入？

### 3. 学术大纲 → 故事大纲
两步走：
1. **学术大纲**：构建完整内容体系，该有的内容尽力收全
2. **故事大纲**：用趣味性、传播性的语言重新组织，让内容生动

## 前策推导要点（博物馆/文化馆）

### 常用叙事起点
1. **地域精神**：「这片土地塑造了什么样的人和文化」
2. **时间长河**：「从过去到现在，什么在变，什么不变」
3. **人物切入**：以代表性人物的命运折射时代
4. **核心问题**：抛出一个引人探索的疑问（如「这片土地为何充满谜团」）

### 主题词风格参考
- 文气意象型：「大哉风物」「求是创新」「星空与大地」
- 提问勾连型：「何以中国」「一城千年」
- 时空型：「古今之间」「溯源寻踪」
- 价值凝练型：「文明的力量」「薪火相传」

### 常见叙事结构
- **时间轴递进**：起源 → 发展 → 高峰 → 当代（梯式，适合历史馆）
- **专题平行**：自然/历史/人文/产业分厅（平行式，适合综合馆/方志馆）
- **感知递进**：感知 → 初识 → 了解 → 拥抱 → 挑战（梯式，适合科普馆）
- **散点意象**：多个文化场景围绕一个地域精神（散点式，适合文化体验馆）

## 大纲结构要点

博物馆大纲常用「部分—组—内容要点」三级结构：

```
展览主题
├── 序厅/绪言（点明主题与原则）
├── 第一部分：[篇章名]
│   ├── 第一组：[小标题] | 内容要点：...
│   ├── 第二组：[小标题] | 内容要点：...
│   └── ...
├── 第二部分：[篇章名]
│   └── ...
└── 尾厅（升华/展望）
```

### 篇章命名技巧
博物馆篇章名常用对仗、押韵、意象化手法增强文气，例如：
- 三段递进式：「群山藏古韵 / 碧水润新章 / 风雅传千年」
- 工整对仗式：「一座山 / 一条河 / 一粒种 / 一方俗 / 一脉魂」

### 内容要点写法
每个二级/三级展区下列出「内容要点」，是具体内容点的清单，不展开描述。例如：
```
第二组：一条河
内容要点：河流名称由来、水系分布、流域文明、沿岸风物
```

### 主题定位原则（档案馆/方志馆类常用）
- 突出专业（以馆藏为主）
- 突出地域（结合本地特色）
- 突出教育（社会教育功能）
- 突出人本（观众视角）
