# 企业展厅策划指南

## 信息收集清单

以下信息需在 Step 2 收集，全部填入 HTML 表单：

### 基本信息
- 企业名称 / 项目名称
- 展厅位置与面积（如分多层，各层面积）
- 项目交付时间节点
- 预算范围（可不填）

### 企业解读
- 企业成立时间、主营业务、核心产品
- 企业品牌 slogan / 使命愿景
- 企业最引以为豪的 1～3 件事
- 近年重大里程碑（获奖、上市、突破）

### 受众分析
- 主要参观人群（政务领导 / 商务合作客户 / 行业合作伙伴 / 内部员工 / 公众）
- 参观目的（品牌认知 / 技术验证 / 商务谈判 / 招聘招商 / 其他）
- 参观后希望留下什么印象

### 内容方向
- 是否有明确的展示重点（产品线 / 技术 / 历史 / 文化 / 未来战略）
- 是否有不能涉及的内容
- 参考的同类展厅（如有）
- 是否有已有品牌视觉体系（VI、色彩规范等）

## 项目分析框架

收到信息后，按以下框架分析：

### 1. 企业本质提炼
找到企业在行业中的真实角色定位：
- 是「幕后推手」还是「台前主角」？
- 是「技术领导者」还是「服务者」？
- 核心竞争力是「产品」「关系」还是「使命」？

### 2. 品牌叙事张力
找到最有力的叙事角度，通常来自以下对比：
- 规模小但影响大（隐形冠军）
- 历史悠久但持续创新
- 技术深厚但贴近生活
- 本土成长但面向全球

### 3. 受众情感需求
不同受众希望感受到：
- 政务领导 → 战略价值、社会责任、政策契合
- 商务客户 → 技术实力、可靠性、合作价值
- 合作伙伴 → 生态共赢、资源互补
- 内部员工 → 归属感、自豪感

## 前策推导要点（企业展厅）

### 常用叙事起点
1. **企业使命叩问**：「为什么这家公司值得存在？」→ 从回答中提炼主题
2. **时间维度**：「20年前是什么 → 今天是什么 → 未来将是什么」
3. **影响力视角**：「这家企业改变了什么/谁」→ 从改变出发定义价值
4. **伙伴视角**：「对合作者来说，选择这家企业意味着什么」

### 主题词风格参考
- 凝练有力型：「汇聚·创造」「以技筑梦」「同行·共赢」
- 意象型：「山海之间」「一粒种子」「光与影」
- 问句型：「何以未来」「为何而造」
- 宣言型：「我们相信」「不止于此」

### 常见叙事结构
- **创业起点 → 核心能力 → 行业影响 → 未来愿景**（梯式，适合历史悠久企业）
- **产品/技术 × 应用场景 × 客户故事**（平行式，适合多产品线）
- **企业文化 → 产品力 → 解决方案 → 生态共建**（金字塔式，适合 B2B 企业）

## 大纲结构要点

企业展厅大纲通常包含：

| 展区 | 内容定位 | 情绪基调 |
|------|----------|----------|
| 序厅/入口 | 品牌第一印象，点题 | 震撼/好奇/认同 |
| 企业历程区 | 创业史、里程碑 | 敬佩/信任 |
| 产品/技术区 | 核心能力展示 | 专业/可靠 |
| 应用/解决方案区 | 客户案例、行业影响 | 共鸣/认同 |
| 生态/合作区 | 伙伴体系、开放共赢 | 归属/期待 |
| 愿景/未来区 | 战略方向、未来想象 | 振奋/激励 |

**注意：** 不是每个展厅都需要所有展区，根据面积和重点取舍。小面积展厅（<200㎡）建议聚焦 3 个核心板块。
