# 概念推导 PPT 生成（Step 6）

主题确认后，可选择生成「概念推导 PPT」逐页文案——把"主题是如何一步步推导出来的"可视化呈现，让甲方跟着思路走完一遍，自然认同结论。

## 第一步：选择推导范式

概念推导的逻辑骨架不取决于项目类型，而取决于**核心信息的性质**。提供三种范式，根据项目特征推荐，用户可改：

| 项目特征 | 推荐范式 |
|---------|---------|
| 多方受众要说服（企业/政府/招商/园区） | ① 受众驱动型 |
| 主题是抽象概念（某种事物、某种理念、某类体验） | ② 概念类比型 |
| 价值/精神升华为第一要务（纪念/教育/红色/校史/行业精神） | ③ 破局立意型 |

询问用户：「概念推导用哪种范式？我推荐【X】，你也可以选其他。」

---

## 范式① 受众驱动型

**逻辑**：先分析"为谁做"，从受众诉求反推主题。理性、稳健、利益相关者认同度高。

**页面骨架：**
```
P1 封面          主题词 + 英文 + 项目名 + 一句话定位
P2 目录          策展思考 / 策展主题 / 叙事逻辑 / 展区图谱
P3 章节页        "策展思考"
P4 给谁看        多类受众收敛为 2-3 个核心场景，各自诉求与转化目标
P5 核心记忆点    观众离开后应记住的 1-3 个关键词（提炼自项目核心）
P6 行业坐标      项目所处的时代/行业位置，把"凭什么"转化为"机遇"
P7 项目定位      宏观 / 中观 / 微观三层定位，锚定核心概念
P8 主题揭晓      大字主题词 + 副标题 + 主题释义（情绪高点）
P9 设问          "如何把主题变成可行走的空间？"（承上启下）
P10 叙事逻辑     展区序列 + 对应观众心理动线
P11 情绪曲线     全馆情绪节奏起伏图
P12 展区图谱     转入完整三级大纲
```

---

## 范式② 概念类比型

**逻辑**：不分析受众，从一个宏大的普世概念切入，用类比+连续设问把主题抬到哲学高度。感性、有冲击力、记忆点强。

**页面骨架：**
```
P1 封面          主题词 + 英文 + 项目名
P2 普世类比      用人人熟知的概念类比（如"它和阳光、空气一样……"）
P3 认知缺口      制造反差："但我们对它却知之甚少"
P4 连续设问      "它是什么？" 一连串追问，引发好奇
P5 层层定义      它是一种 X → 更是一种 Y → 本质是一种 Z（不断拔高）
P6 主题升华      在定义的最高处，主题词自然浮现
P7 主题释义      解释主题的含义与价值
P8 设问          "如何把这个概念变成空间体验？"
P9 叙事逻辑      展区序列 + 体验逻辑
P10 展区图谱     转入完整三级大纲
```

---

## 范式③ 破局立意型

**逻辑**：先否定"千馆一面"的平庸定位，借权威引言或时代命题拔高，落到一个精神性的价值定位。适合价值传承类项目。

**页面骨架：**
```
P1 封面          主题词 + 英文 + 项目名
P2 破局反问      "不做什么"——列出几种平庸的常规定位并否定它（如"不是X馆?不是Y馆?"）
P3 策略要素      用几个创新维度（故事/空间/运营等）重塑定位
P4 内容策略      叙事方法（如双线叙事：理性线讲事实，感性线讲精神）
P5 空间策略      空间体验主张
P6 引言升华      一句权威引言或时代命题，把立意拔高
P7 价值定位      "不是X，是Y"——给出超越常规的精神性定位
P8 章节页        转入"内容"
P9 叙事逻辑      展区序列
P10 展区图谱     转入完整三级大纲
```

---

## 第二步：逐页输出文案

按选定范式，**逐页输出文案**，每页包含：
- **页码与页名**
- **标题文案**（主标题，可含英文）
- **正文/要点文案**
- **视觉提示**（用斜体说明该页的视觉构想，供设计参考）

输出格式示例：
```
### 第 1 页 · 封面
> 主标题：【主题词】
> 英文：【ENGLISH】
> 项目名：【项目全称】
> 一句话定位：【定位句】

视觉提示：……
```

## 第三步：导出

全部页面输出后，询问用户是否需要导出为结构化 Markdown 文件（便于贴进 PPT 设计软件）。

---

## 通用原则

- **推导感**：每一页都是上一页的自然延续，让结论"水到渠成"，不要直接抛主题
- **一页一观点**：每页只讲一件事，一张图、一句话、一个观点
- **情绪节奏**：封面→铺垫→揭晓，主题揭晓页是情绪高点
- **范式可混合**：当项目兼具多重特征时，可借用其他范式的某一页（如受众驱动型也可加一页引言升华）
