# 文旅/主题展馆策划指南

## 信息收集清单

### 基本信息
- 项目名称 / 场馆名称
- 项目类型（城市展示馆 / 规划馆 / 景区展厅 / 沉浸式主题馆 / IP 主题展）
- 场地面积、层高、空间结构特点
- 区位信息（地段、周边交通、客流来源）
- 项目交付时间节点

### 内容与资源
- 核心展示主题（城市文化 / 自然景观 / 特定 IP / 某种体验概念）
- 当地独特的文化/自然资源（差异化的关键）
- 是否有 IP 授权或合作内容
- 政策背景（文旅规划、产业政策）

### 受众与运营
- 目标客群（本地市民 / 亲子家庭 / 年轻打卡群体 / 外地游客）
- 是否需要门票收益 / 二次消费 / 网红打卡传播
- 预期日均客流量
- 运营方诉求（流量 / 营收 / 城市形象 / 研学教育）

### 体验偏好
- 期望的体验类型（沉浸式数字 / 实景互动 / 静态展陈 / 混合）
- 技术预算倾向（重多媒体 / 轻量化）
- 参考的同类网红场馆

## 项目分析框架

### 1. 运营思维前置
文旅/主题馆与其他类型最大的区别：**必须从运营和传播的角度反推内容**。先问：
- 这个馆靠什么吸引人来？靠什么让人愿意传播？
- 哪个点能成为「网红打卡点」？
- 内容如何转化为体验，体验如何转化为消费？

### 2. 资源独特性挖掘
文旅项目成败在于「稀缺度」。找到：
- 这个城市/景区/主题最独一无二的是什么？
- 能否提炼出一个能代表它的「境像」或「IP 形象」？
- 如何把抽象的文化转化为可感知、可拍照、可体验的场景？

### 3. 政策与市场双轮
- 政策面：对接国家/省/市的文旅、数字文化、新质生产力等政策
- 市场面：场景消费时代，「内容+体验」赋能

## 前策推导要点（文旅/主题展馆）

### 常用叙事起点
1. **场景代入**：「当你走进……你会看到/感受到……」
2. **境像提炼**：把城市/主题最鲜明的形象提炼成核心意象
3. **概念定义**：定义一个新概念或新体验（如「沉浸式」「元宇宙文旅」）
4. **情感共鸣**：唤起对一座城、一种生活、一个梦想的向往

### 主题词风格参考
- 意境型：「云上之城」「秘境之约」「星河漫游」
- 概念型：「沉浸·共生」「数字方舟」
- 体验承诺型：「来一场穿越」「遇见未来」
- 在地文化型：「侠影古城」「水乡江南」

### 常见叙事结构
- **空间漫游线**：以参观者的旅程为线索，串联多个体验场景（散点式/梯式）
- **主题板块并列**：多个独立主题体验区（平行式，适合综合体验馆）
- **情绪起伏线**：精心设计情绪峰谷，营造沉浸节奏（梯式）
- **世界观构建**：先立一个世界观/故事背景，所有展区都在其中（立体式，适合 IP 馆）

## 大纲结构要点

文旅/主题馆大纲尤其要标注**体验形式**和**情绪节点**：

```
展览主题（含核心概念/世界观说明）
├── 序厅/入口体验（第一印象，奠定沉浸基调）
├── 体验区 1：[场景名]
│   ├── 子场景 1.1 | 内容：... | 体验形式：... | 情绪：↑
│   └── ...
├── 体验区 2：[场景名]
│   └── ...
└── 高潮区/打卡点 + 出口（情绪峰值 + 消费/传播转化）
```

### 情绪线设计原则
文旅馆比其他类型更强调情绪节奏：
- 设计明显的**情绪峰**（震撼的核心体验点）
- 安排**情绪谷**作为缓冲（让观众喘息）
- 入口要快速「拉高」情绪，制造第一印象
- 出口前设置高潮，留下记忆点和传播点

### 运营点位标注
在大纲中标注可运营/可消费/可打卡的点位，方便后续运营规划。
