# 展览大纲标准框架与模板

展览大纲是「框架性、不涉及具体内容点详细描述的文本」，包含：主题确定、展览定位、展览结构、内容要点。区别于后续的「展览文本」（含具体内容详细创作）。本 skill 止步于大纲。

---

## 大纲层级定义

| 层级 | 名称 | 内容 |
|------|------|------|
| 主题 | 展览主题 | 主题词 + 副标题 + 主题释义 |
| 一级 | 一级展区/部分 | 篇章名 + 该展区定位说明 |
| 二级 | 二级展区/组 | 小标题 + 内容要点 |
| 三级 | 三级展区/展项组 | 展项名 + 具体内容点（可选，视项目深度） |
| 内容 | 内容要点 | 该节点要呈现的具体内容清单 |

---

## 标准输出模板（Markdown 表格版）

最终交付给用户的大纲，使用如下表格格式，便于复制到 Word/Excel：

```markdown
# 展览主题：【主题词】——【副标题】

**主题释义：** （3～5句话说明主题含义与价值）

**叙事线路：** （金字塔式/梯式/平行式/散点式/立体式）

---

| 一级展区 | 二级展区 | 三级展区 | 内容要点 |
|---------|---------|---------|---------|
| 序厅 | — | — | 开篇点题，抛出核心问题/情境 |
| 一、【篇章名】 | 1.1【小标题】 | — | 内容点A、内容点B、内容点C |
| | 1.2【小标题】 | — | 内容点A、内容点B |
| 二、【篇章名】 | 2.1【小标题】 | 2.1.1【展项】 | 内容点A、内容点B |
| | 2.2【小标题】 | — | 内容点A、内容点B、内容点C |
| 尾厅 | — | — | 情感收束，与序厅呼应 |
```

## 树形结构版（用于对话中快速展示）

```
展览主题：【主题词】——【副标题】

序厅：【名称】
  └ 开篇内容/核心问题

一、【一级篇章名】（定位：...）
  ├ 1.1【二级标题】｜内容要点：...
  ├ 1.2【二级标题】｜内容要点：...
  └ 1.3【二级标题】｜内容要点：...

二、【一级篇章名】（定位：...）
  ├ 2.1【二级标题】｜内容要点：...
  └ 2.2【二级标题】｜内容要点：...

三、【一级篇章名】（定位：...）
  └ ...

尾厅：【名称】
  └ 收束内容
```

## 篇章命名手法

好的篇章名能增强展览的文气与记忆度，常用手法：

1. **平铺直叙**：直接表达，如「陶瓷的历史」「企业发展历程」
2. **修饰对仗**：工整对偶，如「群山藏古韵 / 碧水润新章」
3. **意象凝练**：用意象代指，如「一座山 / 一条河 / 一粒种」
4. **递进三段**：层层拔高，如「立足处 / 远眺时 / 登临后」
5. **融合写法**：意象+概念，如「问道千年——一片叶子的故事」

**原则：** 同一展览内，篇章命名风格应统一（要么都对仗，要么都直叙）。

## 内容要点写法

内容要点是「内容点清单」，不是完整文案。写法：

```
第二组：一条河
内容要点：河流名称由来、水系分布、流域文明、沿岸风物
```

- 用顿号分隔多个内容点
- 只列「讲什么」，不写「怎么讲」的文案细节
- 每个二级展区 3～8 个内容点为宜

---

## 大纲自检清单

输出大纲前，检查：

- [ ] 主题是否从项目本质推导而来，而非套用模板
- [ ] 一级展区之间是否符合所选叙事线路的逻辑
- [ ] 篇章命名风格是否统一
- [ ] 序厅是否点题，尾厅是否呼应
- [ ] 各展区内容是否平衡（无某区过重/过轻）
- [ ] 是否符合该项目类型的特殊要求（企业回归品牌/博物馆内容准确/文旅强调体验）
- [ ] 内容总量是否匹配场地面积（避免内容塞不下或撑不满）
